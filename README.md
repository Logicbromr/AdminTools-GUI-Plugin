# AdminTools

Premium admin tools GUI plugin for Paper 1.21.1 servers.

Features
- Admin console GUI with premium styling
- Toggle flight, vanish, god mode, heal, feed
- Teleport to spawn and to players
- World controls for day, time, weather
- Online player list and quick target actions
- Targeted player actions: teleport, heal, feed, kick, ban, OP, inventory view
- Inventory management tools and server utilities

Build

```bash
gradle build
```

Install
1. Build the plugin jar.
2. Place the jar in your Paper server `plugins` directory.
3. Start the server.
4. Use `/adminmenu` or `/am`.

Permissions
- `admintools.use` — access the menu
- `admintools.reload` — reload plugin configuration

This is a premium-style foundation for a Paper admin plugin and is ready to extend with more advanced features.
